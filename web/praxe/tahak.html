Jak tahák číst

Každá tabulka pokrývá jednu skupinu modulů. Sloupec Na co se hodí říká, kde nástroj ušetří nejvíc práce. Sloupec Kdy ho nepoužít je stejně důležitý: popisuje situace, kdy nástroj zdržuje nebo kdy je riskantní. Ceny jsou orientační podle stavu v říjnu 2026 a mění se často. Před nákupem je vždy ověř na webu výrobce. Sloupec Data popisuje, kam odchází to, co do nástroje vložíš. Tohle je téma kapitoly 3 sylabu. Poslední sloupec odkazuje na modul, kde nástroj nastavíš krok za krokem.

Firemní a klientská data

Do cloudového nástroje nevkládej data klientů, interní dokumenty ani kód z firemních projektů, pokud ho zaměstnavatel výslovně neschválil. Nástroj, který si tester zapne sám bez schválení, je shadow AI (stínová AI, sylabus 5.1.1). Na cvičení používej veřejné demo aplikace a vlastní projekty. API klíče patří do proměnné prostředí nebo do Windows Credential Manageru, nikdy do kódu ani do repozitáře.

API klíč

Kurz Gianni Bruno ukládá klíč do souboru openai-key.json v projektu. Takový soubor snadno skončí v gitu. Bezpečnější je proměnná prostředí OPENAI_API_KEY nebo ANTHROPIC_API_KEY, nastavená mimo repozitář. V CI patří klíč do správce tajemství (Jenkins Credentials, GitHub Actions secrets).

Jak vybrat nástroj

Začni otázkou, jaká data do nástroje půjdou. Citlivá data patří jen do nástroje schváleného zaměstnavatelem, nebo do lokálního modelu (GPT4All, Ollama). Teprve potom řeš pohodlí a cenu.

Pro jednorázový úkol, třeba návrh testů z jedné uživatelské story, stačí chat. Pro otázky nad několika dokumenty se hodí NotebookLM, pokud jsou dokumenty veřejné, jinak LocalDocs v GPT4All. Když pracuješ v repozitáři s testy, použij GitHub Copilot nebo Claude Code. Agent má smysl u úkolu, jehož výsledek jde ověřit spuštěním.

Opakovaný proces, který má běžet bez člověka, patří do Pythonu s voláním API a do CI. Proces, který spojuje víc systémů (tabulka, Jira, e-mail), je rychlejší postavit v n8n.
