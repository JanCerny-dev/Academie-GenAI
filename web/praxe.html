Praxe

Návody krok za krokem, jak AI nástroje použít v testování: od chatbota přes GitHub Copilot, MCP a Claude Code po vlastní framework v Pythonu a běh v CI. Podklady jsou dva praktické kurzy (Rahul Shetty: AI Tools for QA, Gianni Bruno: GenAI v Pythonu), výklad je vlastními slovy.

Do cloudových nástrojů nikdy firemní ani klientská data. Cvičení běží na veřejných demo aplikacích (EventHub z kurzu, webdriveruniversity.com, goal-tracker API) nebo na vlastních projektech. API klíče patří do proměnných prostředí, ne do kódu.

Tahle sekce na zkoušku nepřipravuje. Ukazuje, jak pojmy ze sylabu (prompt chaining, RAG, agenti, LLMOps) vypadají v práci. U každého modulu je odkaz na související kapitoly.

Tahák a závěrečný projekt

Tahák porovnává všechny nástroje ze sekce na jedné stránce. Závěrečný projekt spojí moduly do jedné aplikace, kterou jde ukázat na GitHubu.

  • Začni tady

    Tahák nástrojů

    Všechny nástroje ze sekce Praxe na jedné stránce: k čemu jsou, kdy je nepoužít, kolik stojí a kam tečou data.

    15–20 min · začátečník

    ChatGPT, Microsoft Copilot, NotebookLM, GPT4All, Ollama, GitHub Copilot, MCP, Playwright MCP, Claude Code, n8n, ContextQA, OpenAI API, Anthropic API, Behave, Playwright, Jenkins, GitHub Actions

    bez cvičení

    • Otevřít≈ 9 min čtení

  • Na závěr

    Závěrečný projekt

    AI asistent pro test design. Ze specifikace vzniknou testovací podmínky, testovací případy, scénáře v Gherkin a spustitelné testy. Kvalitu výstupu měří metriky ze sylabu a celé to běží v CI.

    40–50 h (4–5 týdnů po 10 h) · pokročilý

    Python 3.12, OpenAI API nebo Anthropic API (volitelně Ollama), Behave, Playwright, requests, pytest, GitHub Actions

    8 cvičení

    • Otevřít≈ 12 min čtení

Nástroje v chatu

Chatboti a aplikace bez programování: prompty pro testovací úlohy, práce s dokumenty, lokální modely.

  • Modul 1

    Prompty pro testera v chatu

    Z dokumentu s požadavky vytvoříš v běžném AI chatu testovací případy, testovací plán, rozdělení testů do pyramidy a kombinace testovacích dat a výsledek zkontroluješ.

    3–4 h · začátečník

    ChatGPT, Microsoft Copilot, Google Gemini nebo NotebookLM, webový prohlížeč, Python 3 (jen krok 10)

    3 cvičení

    • Otevřít≈ 28 min čtení

  • Modul 2

    Lokální modely a ochrana dat

    Rozběhneš jazykový model na vlastním počítači, necháš ho odpovídat z vlastních dokumentů a z Pythonu, a víš, kdy má lokální model v bance smysl a kdy ne.

    3–4 h (plus stahování modelů) · středně pokročilý

    GPT4All, Python 3, volitelně Ollama nebo LM Studio, Hugging Face Transformers (jen ukázka)

    3 cvičení

    • Otevřít≈ 20 min čtení

    Testovací nástroje postavené na LLM

    Vyzkoušíš komerční testovací platformu s LLM na EventHubu od nahrání požadavků po plán vydání a podle vlastních kritérií posoudíš, jestli by obstála na projektu pro banku.

    2–3 h · začátečník

    ContextQA, TestMu AI (KaneAI), testRigor, rozšíření prohlížeče Chrome

    3 cvičení

    • Otevřít≈ 16 min čtení

AI v IDE a agenti

GitHub Copilot ve vývojovém prostředí, MCP servery, Claude Code a skills, n8n a další agenti.

  • Modul 3

    GitHub Copilot pro testera

    S Copilotem ve VS Code postavíš a rozšíříš malý testovací projekt v Pythonu s Playwrightem a pytestem, napíšeš vlastního agenta na návrh scénářů a vyzkoušíš cloudového agenta na GitHubu.

    4–5 h · středně pokročilý

    VS Code, GitHub Copilot, Python 3, pytest, Playwright (pytest-playwright), Git, GitHub; volitelně PyCharm

    3 cvičení

    • Otevřít≈ 23 min čtení

    MCP a Playwright MCP

    Připojíš k LLM prohlížeč, soubory, API a databázi přes MCP servery, necháš agenta projít aplikaci a z jeho průzkumu vznikne Playwright test.

    3–4 h · středně pokročilý

    Model Context Protocol, Playwright MCP, VS Code s GitHub Copilot, Claude Code nebo Claude Desktop, Node.js

    3 cvičení

    • Otevřít≈ 20 min čtení

  • Modul 5

    Claude Code pro QA – skills a agenti nad EventHubem

    Nad kódem EventHubu postavíš řetězec skills, který vytvoří testovací scénáře, rozdělí je do vrstev pyramidy, napíše a spustí Playwright testy, zreviduje je a vydá report pokrytí.

    6–8 h (rozděl do tří večerů) · pokročilý

    Claude Code, Playwright, Playwright MCP, Node.js, VS Code

    3 cvičení

    • Otevřít≈ 37 min čtení

  • Modul 7

    Agent v n8n pro QA workflow

    Postavíš v n8n AI agenta, který přečte tabulku nalezených defektů, nové založí v Jiře a pošle souhrn, a otestuješ, co agent udělá s duplicitami a s podvrženým textem v tabulce.

    2–3 h · středně pokročilý

    n8n, Jira Cloud, Google Sheets, Gmail, OpenAI API nebo Anthropic API

    3 cvičení

    • Otevřít≈ 16 min čtení

    Python 3.12, Behave, Playwright, openai, allure-behave, Allure CLI, VS Code
